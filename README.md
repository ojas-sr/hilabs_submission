# HiLabs Submission: MedCare Provider Roster Portal

Case materials live one level up, outside this repo. Prototype uses **synthetic data only**.

## Structure
- `src/pages/` route-level screens (one folder per route)
- `src/components/` reusable UI (`layout/`, `ui/`)
- `src/services/` API clients and `mock/` synthetic backends
- `src/data/` synthetic datasets
- `src/plugins/` cross-cutting integrations
- `src/shared/` constants, hooks, utils, types
- `src/styles/`, `src/tests/`

## Run
```bash
npm install
npm run dev
```
